# Changelog

## 1.2.1

- Fixed the Helius MCP availability check in the `jupiter`, `okx`, and `svm` skills. They tested for pre-router tool names that the server no longer exposes as tools, so the check could never pass and each skill reported the server as not running.
- Added the action-name translation banner to `jupiter`, `okx`, and `svm`, matching `build`, `dflow`, and `phantom`.
- Every `helius-mcp` install instruction printed by a skill now names the exact pinned version instead of `@latest`, matching `.mcp.json`.

## 1.2.0

- Helius MCP server is now pinned to an exact version (`helius-mcp@2.1.0`) instead of `@latest`, so the code executed on install matches the reviewed commit
- DFlow MCP server removed from the default config — it is now an optional, manually-added connector; the DFlow skill works without it
- `.mcp.json` is generated by `scripts/compile-skills.ts` from `versions.json` and enforced in CI

## 1.0.0 (2026-03-04)

- Initial release
- Build skill: Solana backend development with Helius infrastructure
- DFlow trading skill: Spot swaps, prediction markets, LaserStream, and HFT patterns
- Phantom frontend skill: React, React Native, and browser SDK wallet integration
- SVM skill: Solana protocol internals and architecture research
- Helius MCP server (auto-starts): 40+ live blockchain tools
- DFlow MCP server (auto-starts): Trading API tools and documentation
- Rules: API best practices, transaction safety, and explorer link enforcement
- Agent: Helius Integration Specialist for intelligent skill routing
